1. 1. Open Flex Queries

    Log in to the IBKR Client Portal on the website. In the menu choose Performance & Reports, then Flex Queries.

  2. 2. Create the report

    Next to Activity Flex Query press +. Name it Finance Sentry. In Sections tick exactly these five, and in each one press Select All so every field is included:

    Press Continue, then Create.

  3. 3. Turn on the Flex Web Service and copy the token

    Back on the Flex Queries page, find Flex Web Service and press the gear icon. Switch the service on, press Generate New Token and pick the longest expiry (1 year) so you don't have to redo this often. Leave the IP restriction off. Copy the token that appears.

    When the token expires, syncing stops until you generate a new one and paste it here.

  4. 4. Copy the Query ID

    Return to the list of Activity Flex Queries. The number shown beside Finance Sentry is the Query ID (press the i icon if you don't see it).

  5. 5. Paste both above

    Enter the token and the Query ID, then press Check connection. You'll see your account and what the report contains before anything is saved.
